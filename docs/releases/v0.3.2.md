# v0.3.2 單機穩定版

支援 Debian 13。單機 RouterOS 用戶端回退功能已用 RouterOS 7.24.1 驗證。雙機 HA 不在本版驗收範圍。

## 變更

- 安裝器按 amd64／arm64 固定 sing-box、SmartDNS、AdGuard Home 同 Xray 版本及 SHA256。手動更換上游元件仍用獨立嘅 `update-software`。
- 安裝升級及排程更新期間，以臨時 DNS 接力維持既有過濾同分流，並在磁碟準備交接資料。排程碰到 watchdog 維護鎖會等待重試。
- 單機 RouterOS 可為一部指定 IPv4 用戶端啟用同路徑探測。Scheduler 同時檢查 VM 健康及用戶端最新嘅 UDP／TCP DNS 同 HTTPS 結果。探測失效或逾期會回退，連續兩輪成功後自動接回。配對嘅移除檔會還原原有啟用嘅用戶端路由規則。
- `/healthz` JSON 提供分流同維護狀態。保留既有 HTTP 狀態行為，監控單一分流時應同時檢查 JSON。
- AdGuard Home 可從管理頁面登入，現有 AdGuard 帳戶保留並使用獨立登入。管理 HTTP 應維持在可信 LAN 或既有 VPN 管理路徑。

## 安裝同升級

1. 下載 GitHub Release 嘅 `install.sh` 同 `SHA256SUMS`，用 `sha256sum -c SHA256SUMS` 核對。
2. 由 v0.3.1 升級前，備份 VM 同既有設定，確認可用 console，並用同一 installer 同設定先跑 `--dry-run`。維護期間仍可能有短暫中斷。
3. 升級後驗證 UDP／TCP DNS、廣告過濾、AI／CN／default 出口同排程。需要單機 RouterOS 回退時，按 README 另外生成、匯入並驗證用戶端專用設定。發布同 Linux 升級均唔會自動接管 RouterOS。

隔離環境同指定 LAN 用戶端已驗證回退及自動接回。LAN 測試只改一條測試目的 IP 路由，並以封包確認 DNS 同轉發切回正確路徑。實機測試使用發布前候選，正式 installer 更新版本標記。Debian 13 自動回歸見 GitHub Actions。
