# v0.3.0 — 域名分流、恢復及網頁操作可靠性修補

## 修正內容

### 網頁及設定保存

- 修正候選設定被當作 shell 執行的風險：改用資料解析，保留合法引號、換行及 JSON；拒絕可執行語法、重複／未知欄位及不安全檔案。
- 修正前段 renderer 失敗、後段成功卻回報整體成功的情況；保存、產生設定、重啟及驗證任一步失敗都會到達交易邊界。
- IPsec、出口模式／outbound、SOCKS、MSS、本機名稱、更新時間及域名批次改用一致的保存／驗證／回復流程，避免只套用一半。
- 網頁持久變更回傳 operation ID，顯示處理中、已提交、已回復或需介入；關閉瀏覽器不會取消工作，重新連線不會自動重送。後端鎖拒絕衝突寫入。
- 中斷、期限到達或恢復失敗時保留恢復記錄及私有備份，使用獨立 systemd guard；未解決的恢復狀態會阻止新寫入。

### DNS、域名分流及手機回家路徑

- 修正共享 CDN IP 導致不同域名互相影響分流的情況，保留以域名決定出口的核心原則。
- 對已驗證的 WeChat 圖片 CDN 及小紅書 API 精確保留原目的 IP，減少服務端重新解析後選到不同端點的失敗；沒有全局套用此例外。
- 修正 default DNS 的 HTTPS 紀錄處理、SmartDNS 分組與慢上游／cache 前置檢查；AI/CN 仍維持 IPv4 保護，沒有把其他中國服務擴入 CN。
- 修補 sing-box／Xray 域名資訊傳遞、來源地址及既有連線遷移的相關邊界，保留 VLESS＋REALITY 與 SOCKS 轉接架構。

### IPsec、健康檢查及啟動恢復

- 修正 IPsec 換鑰及 VIP／policy 驗證，將控制面狀態與真正資料面連通分開判定。
- AI/CN 各自要求新鮮、正向的資料面證據才開啟 readiness gate；失敗維持保護性關閉，不將「沒有證據」當作成功。
- 修正 watchdog 的期限、profile 隔離與 nft 更新／回復，避免處理一個 profile 時誤動另一個。
- 補齊啟動時檔案恢復先於網絡／業務服務的順序，以及備份完整性、SQLite 一致性與服務恢復處理。
- 一般持久操作上限為 300 秒，恢復預留 150 秒，獨立 guard 為 510 秒；失敗不會無限制延長期限。

### 資源、診斷及私隱

- 限制 HTTP body、讀取期限及同時處理請求數；soak 共用單例與參數限制，未完成 future 及延遲樣本有固定上限。
- 改善 support bundle 對憑證、URI、token、地址及 session 的遮罩。
- 出口表單的語法檢查不再宣稱遠端連通；已存出口診斷不覆寫正式設定。
- 更新排程文案清楚區分域名資料更新及顯式軟件更新。
- 移除實際部署地址及 VPN 端點；wizard／example 使用中性示例。公開提交不含原始調查報告、封包、帳密、私有測試副本或個人路徑。

## 驗證與限制

- 發布候選的 installer contract（含 runtime reliability）exit 0／468.786秒；操作生命週期29案、HTTP限制12案、Xray配置12案及網頁變更31案均通過，另有DNS、分流、資料面、遮罩與資源限制定向回歸通過。缺少本機SmartDNS的native慢上游案例明確skip，不計作實機通過。
- 本次發布前的功能候選曾完成隔離 nft／交易、SIGTERM／SIGKILL、服務失敗、私有 PID1 啟動恢復及發布回復的分層驗證；這些不是整台主機核心重啟測試。
- 對應功能候選已完成部署後兩輪 DNS、SOCKS、default、網頁及 AI/CN 資料面驗收，並透過實際 HTTP API 暫改更新時間再還原。發布去識別化及版本標記後的檔案不冒稱相同部署雜湊。
- 歷史容量測試保留原有失敗判定，只作恢復時限 sizing 依據；沒有宣稱所有容量情境通過。
- Streisand 的部分 iOS 小程序／通知問題仍不能宣稱全部修復。同節點 V2Box 對照可用，亦不足以把所有客戶端故障歸因於伺服器或承諾所有 App 正常。

## 升級注意

1. 先保留現有設定及可用備份，核對 release 附件的 SHA256。
2. 示例 VPN 網域不能直接連線；新裝須填入自己的伺服器、Remote ID 及帳密。既有部署應沿用自己的完整設定，不以示例覆蓋。
3. 先執行 `bash install.sh --dry-run --config /path/to/config.env`，核對後才進行正式安裝／升級；必要服務重啟會造成短暫中斷。
4. `routeros-policy` 的 SOCKS 使用所設定 LAN 地址及 port `10800`。保留域名分流及既有 CN 視頻範圍；不要求改為所有中國網站走 CN。
5. 本 release 不會因在 GitHub 發布而自動更新正在運行的主機，亦不降級 Xray 或變更用戶帳戶。
